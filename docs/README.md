# 🌸 FloraX – Flower Exchange Platform

FloraX is a flower exchange platform concept designed to connect flower growers, sellers, and buyers through a digital marketplace.

This project explores flower trading workflows, order management, and user-friendly interface design. It began with a console-based C++ prototype and evolved through collaborative UI redesign and quality assurance activities.

## 🎯 Project Objectives

- Explore digital solutions for flower trading.
- Simplify flower buying and selling workflows.
- Improve the user experience through UI redesign.
- Apply software testing and quality assurance practices.

## ✨ Key Features

- Flower listing and browsing
- Buy and sell order workflows
- Order management
- Flower market information
- User-friendly interface design

*Note: Features may vary depending on the current implementation.*
